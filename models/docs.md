Аналитическое хранилище магазина

В этом проекте мы собираем аналитическое хранилище магазина на базе Greenplum и dbt.

Данные обрабатываем в три этапа:
staging - берём исходные данные и подготавливаем их для дальнейшей работы
intermediate - объединяем данные из разных таблиц и делаем промежуточные расчёты
marts - собираем итоговые таблицы, которые уже можно использовать для аналитики<

Всего сделали пять витрин:
fct_orders - информация о заказах и оплатах 



fct_order_items - товары внутри каждого заказа  



dim_customers - информация о клиентах и их покупках



dim_products - товары, бренды и категории



dim_dates - календарь для анализа продаж по датам
